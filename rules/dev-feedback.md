# dev-feedback

## User 프로파일
- **언어**: 한국어 답변·진행 보고, 코드 식별자·기술 용어는 원문 유지
- **선호 방식**: 탐색은 사전 질문 없이 진행하고, 첫 구현 직전에 "수정 대상 / 변경 내용 / 예상 영향"을 제시해 승인받기
- **커밋 스타일**: Conventional Commits (`feat(ui):`, `fix(app):`, `docs(release):`), 본문 한국어 허용
- **결정 패턴**: 권장안 1개 + 근거를 제시하고 사용자가 선택. 시각 결과물은 사용자가 직접 보고 확정

## 반복 피드백 패턴
- 리뷰·비교 리서치는 서브에이전트에 나눠 병렬로 실행하고, lead가 결과를 합쳐 제품 목표 기준으로 우선순위화
- 메모장 느낌의 경량 UX를 먼저, Markdown/표는 그다음 (CLAUDE.md Boundaries)

## 금지/비선호 패턴
- 탐색·문서 갱신만 2턴 넘게 연속하기 (구현·검증·블로커 보고 중 하나로 넘어갈 것)
- 쓰일 곳이 증명되지 않은 wrapper·report·preview 계층 추가
- Microsoft Notepad의 브랜딩·아이콘·문자열·리소스 복사
- 포트 3000 사용, `.bak` 백업 (백업은 git으로)

## 학습 패턴 (recurring-mistakes)
- 하네스로 띄운 WPF 세션에서 `WINDIR`가 빠질 수 있음. 실행 확인은 표시되는 데스크톱 세션 기준
- 시작 CWD가 문서 폴더에 잠기는 문제 (`010fbb9`에서 앱 기준 폴더로 리셋해 해결)
