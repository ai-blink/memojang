# Dev Brief

Purpose: Memojang is a Windows 11 Notepad-like editor with Markdown/table support and optional capture exclusion.

Current product target: .NET 10 WPF desktop app for Windows 11.

Core value:
- Keep Notepad speed and familiarity.
- Add Markdown rendering and table editing where plain Notepad is weak.
- Make privacy mode explicit and honest rather than overpromising security.

Primary plan: `notes/plans/2026-07-06-memojang-program-plan.md`

Operator mode:
- Prefer small, verifiable slices.
- Keep implementation decisions traceable to `doc/INTENT.md` and `rules/dev-roadmap.md`.
- Record blockers in `rules/dev-progress.md`; record durable policy decisions in `rules/dev-decisions.md`.
