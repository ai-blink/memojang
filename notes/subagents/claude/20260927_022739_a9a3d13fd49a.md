# Memojang 유사 제품 비교 리서치 (2026-09-27)

메모장 계열 9종, Markdown 편집기 6종, 캡처 제외 사례 7종을 조사했습니다. 기존 리서치(미리보기·이미지 에셋 저장·사이드카 폴더)와 겹치는 내용은 빼고 새 비교 축만 다뤘습니다. 스타 수·라이선스·마지막 push는 GitHub API로 직접 받은 값입니다(`gh`는 `GITHUB_TOKEN`이 무효라 인증 없는 API를 썼습니다). 확인하지 못한 값은 "미확인"으로 적었습니다.

**가장 먼저 봐야 할 것 (Memojang 코드 직접 확인)**
- **인코딩 결함:** 모든 파일을 `File.ReadAllText`로 열고, 저장은 원본과 상관없이 BOM 없는 UTF-8로 고정합니다(`MainWindow.Files.cs:136`).
  - CP949/EUC-KR 파일을 열면 글자가 깨지고, 그대로 저장하면 원본이 망가질 수 있습니다.
  - BOM이 있던 파일은 저장할 때 BOM이 말없이 사라집니다.
  - INTENT의 V1 조건 "예측 가능한 인코딩/줄바꿈으로 저장"에 직접 걸리는 문제입니다.
- **캡처 제외 적용 범위:** 메인 창은 `AllowsTransparency`를 쓰지 않아 affinity를 걸 수 있는 조건입니다. 하지만 메뉴 하위 `Popup`은 `AllowsTransparency=True`입니다(`Styles/Controls.xaml:129`).
  - WPF에서 팝업·컨텍스트 메뉴·툴팁·대화상자는 메인 창과 별개의 HWND입니다.
  - 그래서 메뉴를 열어 둔 상태는 캡처에 찍힐 가능성이 높습니다. 추론이며 실측이 필요합니다.
  - 적용 결과는 `SetWindowDisplayAffinity` 반환값만 믿습니다. `GetWindowDisplayAffinity`로 다시 확인하지 않습니다.

## 3. UI/UX 패턴 레퍼런스

- **탭과 타이틀바 통합:** Notepads는 `SetTitleBar(AppTitleBar)`로 탭 줄을 드래그 영역으로 씁니다([ThemeSettingsService.cs](https://github.com/0x7c13/Notepads/blob/master/src/Notepads/Services/ThemeSettingsService.cs)). Win11은 탭 제목을 내용에서 자동으로 만들고, 새 파일을 새 탭과 새 창 중 어디에 열지 설정합니다. Memojang의 탭형 제목 줄과 같은 방향입니다.
- **Mica와 테마 추종:** Win11 메모장은 Mica, 둥근 모서리, 시스템 테마 추종에 직접 선택도 제공합니다([2021 블로그](https://blogs.windows.com/windows-insider/2021/12/07/redesigned-notepad-for-windows-11-begins-rolling-out-to-windows-insiders/)). Notepads는 "Windows 강조색 사용"과 배경 틴트 불투명도를 둡니다. WPF에서 Mica를 쓰려면 `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE)`가 필요합니다. **이때 `AllowsTransparency=True`로 바꾸면 캡처 제외가 깨지니 쓰면 안 됩니다**(4절 참고).
- **상태바 구성:** Notepads는 수정 표시, 줄바꿈, 인코딩, 줌 %와 슬라이더를 두고, 인코딩·줄바꿈 칸을 누르면 flyout이 뜹니다. Win11은 문자 수와 Markdown 서식/문법 토글을 둡니다. Notepad++는 길이, 줄 수, Ln/Col/Sel, 줄바꿈, 인코딩을 표시합니다.
- **Markdown 미리보기 배치:**
  - Notepads·ghostwriter(`Ctrl+M`)는 분할 방식입니다.
  - Markdown Monster는 `F12` 분할과 `Shift+F12` 분리 창을 쓰고 스크롤을 동기화합니다.
  - Win11은 **한 화면 WYSIWYG ↔ 문법 보기**를 상태바 토글로 바꾸고, 설정에서 서식 기능 전체를 끌 수 있습니다([2025-05 블로그](https://blogs.windows.com/windows-insider/2025/05/30/text-formatting-in-notepad-begin-rolling-out-to-windows-insiders/)).
  - Typora·MarkText는 라이브 방식에 `Ctrl+/`, `Ctrl+E`로 소스를 토글합니다.
- **표 편집 UX:**
  - **Win11 메모장이 이미 표 삽입과 우클릭 행/열 추가·삭제까지 제공합니다**([2025-11 블로그](https://blogs.windows.com/windows-insider/2025/11/21/notepad-update-begins-rolling-out-to-windows-insiders/)). Memojang 표 도우미를 평가하는 최소 기준이 이 수준으로 올라갔습니다.
  - MarkText: 열에 마우스를 올리면 정렬 3개, 좌·우 열 삽입, 열 삭제 툴바가 뜹니다. 행은 가장자리 바에서 위·아래 삽입과 삭제를 합니다([#5442](https://github.com/marktext/marktext/issues/5442)).
  - Typora: `Ctrl+T`로 행×열 대화상자를 열고, `Ctrl+Enter`로 행 추가, `Ctrl+Shift+Backspace`로 행 삭제합니다. 표 툴팁에 정렬 버튼이 있습니다([Table-Editing](https://support.typora.io/Table-Editing/)).
  - Markdown Monster: 그리드 대화상자입니다. 마지막 셀에서 Tab을 누르면 행이 추가되고, `Alt+Shift+↑↓`로 행 삽입, `Alt+←→`로 열을 옮깁니다. CSV·클립보드에서 표를 만들 수 있습니다([문서](https://markdownmonster.west-wind.com/docs/Embedding-Links-Images-Tables-and-More/Embedding-Tables.html)).
  - Advanced Tables·Zettlr: 소스 안에서 Tab/Shift+Tab/Enter로 셀을 옮길 때마다 표를 자동 정렬합니다([Zettlr 표](https://docs.zettlr.com/en/editor/tables/)).
- **이미지 붙여넣기 UX:**
  - Obsidian·Typora: 대화상자 없이 `Pasted image YYYYMMDDHHmmss.png`로 바로 저장합니다([포럼](https://forum.obsidian.md/t/naming-pasted-image-options-in-settings/5792)).
  - Markdown Monster: 미리보기가 있는 파일명 입력 대화상자를 띄우고, PNG는 최대 압축합니다([문서](https://markdownmonster.west-wind.com/docs/Embedding-Links-Images-Tables-and-More/Embedding-Images.html)).
  - Zettlr: 붙여넣기 대화상자에 원본 크기를 기본값으로 채웁니다.
  - Memojang은 이미 클립보드 비트맵을 PNG로 붙여넣으니, 참고할 것은 파일명 규칙 정도입니다.

## 4. 캡처 제외 선행 사례와 한계

**사례**

| 앱 | 스택 · 라이선스 · 스타 | 적용 방식 | 사용자 표시 |
|---|---|---|---|
| [KeePassXC](https://github.com/keepassxreboot/keepassxc/pull/6030) | Qt · NOASSERTION · 29.0k★ | 자기 창과 모든 자식·모달 창. 시스템 파일 대화상자는 `WM_NCCREATE`를 가로채 보호 | **기본 켜짐**. 해제하면 모든 창 제목에 `[Screen Capture Allowed]`와 상시 경고. 해제 값이 저장되지 않아 불만([#11230](https://github.com/keepassxreboot/keepassxc/issues/11230)) |
| [Signal Desktop](https://signal.org/blog/signal-doesnt-recall/) | Electron · AGPL-3.0 · 16.6k★ | Electron `setContentProtection`, 즉 `WDA_EXCLUDEFROMCAPTURE`([Electron 문서](https://www.electronjs.org/docs/latest/api/browser-window)) | Win11에서 기본 켜짐. 끌 때 경고 대화상자. 접근성 도구 영향을 공개 |
| [Bitwarden](https://bitwarden.com/help/app-settings/) | Electron · NOASSERTION · 13.8k★ | 자기 창 | "Allow screen capture" 토글. 문구가 "**most** screenshots"로 보장 범위를 한정 |
| [CopyQ](https://github.com/hluk/CopyQ/pull/3206) | Qt · GPL-3.0 · 12.3k★ | 자기 창(2025-09 머지) | 옵션 이름과 기본값 미확인 |
| [Invisiwind](https://github.com/radiantly/Invisiwind) | Rust · MIT · 479★ | **다른 프로세스에 DLL 주입** | README에 백신 오탐 경고와 "2004 미만에서는 검은 화면" 경고 |

1Password에는 이 기능이 없습니다(기능 요청만 있음, [커뮤니티](https://www.1password.community/discussions/1password/feature-request-hide-1password-windows-from-screen-capture-applications/133552)).

**한계**
- **공식 문서 기준** ([MS Learn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)):
  - 대상은 호출한 프로세스가 소유한 최상위 창뿐입니다.
  - DWM이 합성할 때만 동작합니다.
  - 휴대폰으로 화면을 찍는 것은 막지 못한다고 공식적으로 적혀 있습니다.
- **캡처 경로별:**
  - BitBlt, WGC(OBS·Teams·Zoom·PrintScreen)는 막힌다는 2차 출처가 있습니다([IOActive](https://www.ioactive.com/signal-windows-desktop-contentprotection-bypass/)).
  - DXGI Desktop Duplication은 대체로 막히지만, 특정 GPU 경로로 우회될 수 있다는 단서가 있습니다.
  - RDP, VM 호스트, Miracast, 캡처카드는 공개된 실측이 없어 미확인입니다.
- **Recall:** 공식 개발자 문서가 예로 드는 것은 **`WDA_MONITOR`**입니다([Recall 문서](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/recall/)). `WDA_EXCLUDEFROMCAPTURE`가 Recall에서 통한다는 근거는 Signal의 주장 같은 간접 근거뿐이라 **실측이 필요합니다**.
- **우회:** 같은 사용자 권한의 코드가 원격 스레드나 훅 DLL로 대상 프로세스 안에서 `WDA_NONE`을 호출하면 해제됩니다(IOActive, [MS Q&A](https://learn.microsoft.com/en-us/answers/questions/1653885/setwindowdisplayaffinity-bad-usecase)). 다른 프로세스에서 직접 호출하면 `ACCESS_DENIED`입니다.
- **WPF 특이점:**
  - `AllowsTransparency=True`인 레이어드 창에서는 지원되지 않고, 이때 **오류 0x8(`ERROR_NOT_ENOUGH_MEMORY`)이 엉뚱하게 반환됩니다**([MSDN 아카이브](https://learn.microsoft.com/en-us/archive/msdn-technet-forums/7ce400f0-ebda-4b95-869c-85b5b93f972d), [Q&A 1293302](https://learn.microsoft.com/en-us/answers/questions/1293302/not-able-to-disable-screen-capture-in-wpf-using-se)).
  - Win11 일부 기기에서도 같은 0x8 실패 보고가 있습니다([Q&A 700122](https://learn.microsoft.com/en-us/answers/questions/700122/setwindowdisplayaffinity-on-windows-11)).
  - `ShowInTaskbar`를 바꿔도 HWND는 다시 만들어지지 않습니다(dotnet/wpf 소스 확인). 숨김·표시 뒤에도 affinity가 유지되는지는 미확인입니다.
- **표시 방식:** 2004 이상에서는 창이 캡처에서 아예 빠지고 뒤 화면이 보입니다. `WDA_MONITOR`에서는 검은 사각형으로 찍힙니다.

## 5. Memojang 차용 추천 Top 8

메모장 경량 우선이라는 제품 목표에 맞는 것만 골랐습니다. 코드 복사 없이 동작만 참고하는 것을 전제로 합니다.

| # | 항목 | 출처 | 난이도 | 비고 |
|---|---|---|---|---|
| 1 | **인코딩 감지 + BOM 보존 + "다시 열기/변환해 저장" 분리** (상태바 인코딩 칸 클릭 메뉴) | Notepads, Notepad++, Notepad3 | 중 | V1 인수 조건과 직결되고, 한국어 CP949 파일 손상 위험이 있어 **가장 우선**입니다. .NET에서는 `CodePagesEncodingProvider` 등록이 필요합니다 |
| 2 | **세션 복원/핫엑시트** (`%LOCALAPPDATA%\Memojang\session\`, 원본 파일은 건드리지 않음, 끌 수 있음) | Win11 메모장, Notepads, NotepadNext | 중 | 기존 `settings.json` 저장소 옆에 두면 됩니다. 원본 자동저장은 넣지 않습니다 |
| 3 | **외부 변경 감지**: 미수정 문서는 조용히 다시 읽고, 수정 중이면 "내 것 유지 / 디스크 것 불러오기"를 묻고, 삭제·이동은 상태바에 표시 | Markdown Monster 규칙, Notepads 상태바 아이콘 | 하~중 | 창이 활성화될 때 한 번 확인하는 방식이 `FileSystemWatcher`보다 단순합니다 |
| 4 | **Ctrl+휠 줌** | Notepad++, Notepads | 하 | 기존 `AdjustZoom`에 연결만 하면 됩니다 |
| 5 | **상태바 문자 수(선택 영역 포함) + 누르면 상세 팝업** (공백 포함·제외, 한국어는 문자 수 우선) | Win11, Typora, Obsidian | 하 | |
| 6 | **표 안에서 Tab/Shift+Tab/Enter로 셀 이동 + 이동할 때 자동 정렬 + 마지막 셀에서 Tab이면 행 추가** | Advanced Tables, Zettlr, Markdown Monster | 중 | 표 밖에서는 Tab을 그대로 입력해 메모장 감각을 유지합니다 |
| 7 | **표 우클릭 메뉴**: 행 위·아래 삽입/삭제, 열 좌·우 삽입/삭제, 정렬 좌·가운데·우 | Win11 메모장, MarkText, Typora | 중 | Win11 메모장이 기준선입니다. `Ctrl+T`는 탭 단축키와 충돌하는지 확인해야 합니다 |
| 8 | **캡처 제외 상태를 더 정직하게** | Bitwarden, Signal, KeePassXC, MS Learn | 하 | 세부 내용은 아래에 정리했습니다 |

8번 캡처 제외 상태 개선의 세부 내용입니다.
- `GetWindowDisplayAffinity`로 다시 확인한 뒤에만 "적용됨"으로 표시합니다.
- 오류 0x8은 "메모리 부족"이 아니라 "이 환경에서 지원 안 됨"으로 번역해 보여 줍니다.
- 문구에 "대부분의" 같은 한정어를 넣고, 휴대폰 촬영·다른 기기·악성 코드처럼 **못 막는 경로를 명시**합니다.
- **메뉴·팝업·대화상자는 보호되지 않는다는 점**을 공개하고, 수동 매트릭스에 행으로 추가합니다.
- 수동 매트릭스에 Recall·RDP·OBS 모드별 행도 추가합니다.
- 기본값을 켤지 끌지는 제품 결정이라 제 권고에서 뺐습니다.

**차순위(V2):** 탭을 끌어 창 분리, 미리보기 분리 창(Markdown Monster `Shift+F12`), 포커스 모드, 아웃라인 사이드바, 미저장 변경 diff(Notepads), Mica 배경.

**라이선스 주의**
- **코드 차용 금지:** GPL-3(NotepadNext, Notepad++, Zettlr, ghostwriter)는 옮기면 Memojang 전체가 GPL이 됩니다. AGPL-3(Signal)도 같은 이유로 금지입니다. Markdown Monster는 소스는 보이지만 재배포 금지라 금지입니다. 라이선스 파일이 없는 NotepadWPF와 PolyForm-NC인 Inklet도 금지입니다. Win11 메모장·Typora·Obsidian은 독점이라 동작만 참고하고, 브랜딩·문자열·아이콘은 쓰지 않습니다(CLAUDE.md 규칙).
- **고지를 유지하면 차용 가능:** Notepads(MIT, 다만 UWP 의존이라 WPF에는 설계만 참고), MarkText·Invisiwind(MIT), Notepad3·Notepad2e(BSD-3).

**확인한 것:** 요청한 5개 항목을 모두 다뤘습니다. 스타 수·라이선스·마지막 push는 API 응답값입니다. Memojang 현황(인코딩 고정, Ctrl+휠 없음, 팝업 `AllowsTransparency`, 클립보드 비트맵 붙여넣기 있음)은 `src/Memojang.App` 코드를 grep하고 읽어서 확인했습니다. 파일은 만들거나 수정하지 않았습니다.

관련 파일:
- `C:\ai\projects\memojang\src\Memojang.App\MainWindow.Files.cs`
- `C:\ai\projects\memojang\src\Memojang.App\WindowsInterop\CaptureExclusion.cs`
- `C:\ai\projects\memojang\src\Memojang.App\Styles\Controls.xaml`

result: Memojang 유사 제품 22종을 비교했고, 차용 추천 Top 8 중 1순위는 인코딩 감지와 BOM 보존입니다. 현재 모든 파일을 BOM 없는 UTF-8로 저장해 CP949 파일이 망가질 수 있어서입니다. 그다음은 세션 복원, 외부 변경 감지, 표 Tab 셀 이동 순입니다. 캡처 제외 쪽은 메뉴 팝업이 보호되지 않을 가능성과 Recall 효과가 미확인이라는 점을 짚었습니다.
