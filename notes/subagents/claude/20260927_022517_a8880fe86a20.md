## 2. Typora (상용)

- **기술 스택·라이선스·버전**: 상용 제품입니다. 기술 스택과 최신 버전은 이번 조사에서 미확인입니다.
- **표 편집 UX**:
  - `Ctrl+T`를 누르면 **행·열 수를 정하는 대화상자**가 뜹니다. 6열·10행을 넘기려면 숫자를 직접 입력합니다.
  - 커서가 표 안에 있으면 **표 툴팁**이 뜹니다. 맨 왼쪽 아이콘으로 크기를 조정하고, 열 정렬 버튼(좌·우·가운데·기본)이 있습니다.
  - 행·열 경계를 끌어서 순서를 바꿀 수 있습니다.
  - 행 추가는 `Ctrl+Enter`(신버전은 Tab도 가능), 행 삭제는 `Ctrl+Shift+Backspace` 또는 `Shift+Alt+Ctrl+L`, 열 추가·삭제는 우클릭 메뉴입니다.
  - 출처: https://support.typora.io/Table-Editing/ · https://support.typora.io/Shortcut-Keys/
- **이미지 붙여넣기**:
  - 저장 위치를 먼저 설정해야 붙여넣기가 됩니다. 붙여넣는 순간 바로 복사되고 참조가 삽입되며, 대화상자는 없습니다(문서상 언급 없음).
  - 파일명은 날짜·시각 기반이지만 정확한 포맷은 미확인입니다.
  - 이미지 삽입 단축키는 `Ctrl+Shift+I`입니다.
  - 출처: https://support.typora.io/Images/ · https://github.com/typora/typora-issues/issues/1473
- **미리보기·모드**:
  - 라이브(WYSIWYG) 방식이고 소스 모드 토글은 **`Ctrl+/`** 입니다.
  - 포커스 모드 `F8`: 현재 블록 외에는 흐리게 표시합니다.
  - 타자기 모드 `F9`: 커서를 화면 가운데에 고정합니다. "마우스로 클릭할 때도 가운데 유지"를 끄는 옵션이 있습니다.
  - 아웃라인 `Ctrl+Shift+1`, 사이드바 `Ctrl+Shift+L`.
  - 출처: https://support.typora.io/Focus-and-Typewriter-Mode/
- **자동저장**: Windows에서는 설정에서 켜야 하고 기본 5분 간격입니다(`conf.user.json`의 `autoSaveTimer`). **"Recover Unsaved Drafts"** 기능이 있고 백업 파일명은 `{date}-{filename}.md`입니다. 외부 변경 감지와 인코딩 처리는 미확인입니다. (https://support.typora.io/Auto-Save/)
- **통계**: Windows에서는 **상태바에 단어 수**가 뜹니다. 버튼을 누르면 팝업에 줄 수·문자 수·**예상 읽기 시간**이 나옵니다. 텍스트를 선택하면 선택 영역만 셉니다. (https://support.typora.io/Word-Count/)

- **기술 스택**: WPF + MahApps.Metro. 편집기는 **웹브라우저 컨트롤 안의 Ace Editor**, 렌더링은 **Markdig**, 맞춤법 검사는 nHunspell, 애드인은 .NET입니다. WebView2 전환 여부는 이번에 본 원문에서 미확인입니다. (https://github.com/RickStrahl/MarkdownMonster)
- **표 편집 UX** (가장 상세함):
  - **별도 대화상자 + 그리드** 방식이고, 현재 미리보기 테마와 같은 **라이브 미리보기 창**이 붙어 있습니다.
  - 셀 이동: Tab으로 다음 필드, **마지막 셀에서 Tab을 누르면 행이 자동 추가**됩니다. 방향키로 셀 이동, `Ctrl+방향키`로 여러 줄 필드 안에서 이동합니다.
  - 행 조작: `Alt+Shift+Down/Up`으로 위·아래 행 삽입, `Alt+Shift+Del`로 행 삭제, `Alt+Up/Down`으로 행 순서, `Alt+Left/Right`로 열 순서를 바꿉니다.
  - 툴바와 컨텍스트 메뉴에는 밑줄 액셀러레이터가 있습니다(A 위, B 아래, D 행 삭제, L·R 왼쪽·오른쪽 열 등).
  - 열 정렬은 컨텍스트 메뉴에서 `:Left`, `Right:`, `:Center:`로 지정합니다.
  - **Markdown 편집기·클립보드·JSON·CSV에서 표를 만들 수 있습니다.** 출력 형식은 Pipe / Grid / HTML 세 가지입니다.
  - 기존 표를 **우클릭 → Edit Table로 다시 열어 재포맷**합니다(양방향 편집).
  - ESC로 취소하면 "반영 / 버림 / 편집기로 돌아가기"를 묻습니다.
  - 출처: https://markdownmonster.west-wind.com/docs/Embedding-Links-Images-Tables-and-More/Embedding-Tables.html · https://github.com/RickStrahl/MarkdownMonster/blob/main/TipOfTheDay.md
- **이미지 붙여넣기**:
  - `Ctrl+V` 또는 편집기 컨텍스트 메뉴의 "Paste Image"를 쓰면 **파일명을 묻는 대화상자가 뜨고 이미지 미리보기를 보여 줍니다.**
  - PNG는 자동으로 최대 압축하고, JPEG 품질 기본값은 80입니다(`JpegImageCompressionLevel`).
  - 툴바의 Image 대화상자는 파일을 고르지 않았을 때 클립보드 이미지를 자동으로 가져옵니다.
  - 화면 캡처 기능이 내장돼 있습니다.
  - 출처: https://markdownmonster.west-wind.com/docs/Embedding-Links-Images-Tables-and-More/Embedding-Images.html
- **미리보기**: **스크롤 동기화 분할 미리보기**를 `F12`로 토글하고, **외부 미리보기 창(멀티 모니터용)**은 `Shift+F12`입니다. 외부 브라우저 미리보기도 됩니다. 방해 금지 모드는 `Alt+Shift+Enter`, 프레젠테이션 모드는 `F11`입니다. (https://markdownmonster.west-wind.com/docs/Features.html)
- **세션·저장·외부 변경**:
  - 기본적으로 **열었던 문서를 기억**합니다(끌 수 있음). Auto-Save와 Auto-Backup이 있습니다.
  - **외부 변경 감지 규칙**:

    - 수정 중인 문서는 저장할 때 **Use Yours / Use Theirs / Compare(외부 Diff 도구)** 중에서 고르게 합니다.
  - 인코딩: 과거에 UTF-8을 BOM 포함으로 자동 변환하는 문제가 이슈 #48로 보고됐습니다. 현재 동작은 미확인입니다.
  - 출처: https://markdownmonster.west-wind.com/docs/Common-Tasks/File-Change-Detection-in-the-Editor.html · https://github.com/RickStrahl/MarkdownMonster/issues/48
- **통계·아웃라인**: 줄 수·단어 수를 표시합니다. **동기화 문서 아웃라인**은 `Alt-V-O`, 사이드바는 `Ctrl+Shift+B`입니다. 코드 폴딩과 인라인 맞춤법 검사도 있습니다.

## Memojang에 경량으로 차용할 만한 것 5개

전제: WPF, FlowDocument 미리보기, 파이프 표 도우미가 이미 있습니다.

1. **Tab 셀 이동 + 이동 시 자동 정렬 포맷** (Advanced Tables·Zettlr·MM 방식)
   - 소스 편집기 안에서 파이프 표에 커서가 있을 때만 Tab / Shift+Tab / Enter를 가로챕니다. 셀을 옮길 때 기존 표 도우미의 정렬 포맷을 다시 적용합니다.
   - **마지막 셀에서 Tab을 누르면 새 행을 추가**합니다(MM).
   - 표 밖에서는 Tab을 일반 입력으로 둬서 메모장 감각을 유지합니다. 그리드 대화상자(MM)보다 훨씬 가볍고, 텍스트가 곧 정본이라는 원칙도 지킬 수 있습니다.
2. **표 우클릭 메뉴와 단축키 세트** (MarkText 열 툴바의 6개 동작 + MM 키 배치)
   - 행: 위에 삽입 / 아래에 삽입 / 삭제. 열: 왼쪽에 삽입 / 오른쪽에 삽입 / 삭제 / 정렬 좌·가운데·우.
   - 단축키 후보: `Alt+Shift+Up/Down`(행 삽입), `Alt+Shift+Del`(행 삭제), `Ctrl+Enter`(행 추가, Typora).
   - 삽입은 "행×열 입력 대화상자"(Typora `Ctrl+T` 방식) 하나면 충분합니다. 다만 `Ctrl+T`는 탭 기능과 충돌할 수 있으니 현재 `MainWindow.Tabs` 바인딩과 대조해야 합니다.
3. **클립보드 이미지 붙여넣기는 무대화상자 + 타임스탬프 이름을 기본으로** (Obsidian·Typora 방식)
   - 기본값은 `Pasted image YYYYMMDDHHmmss.png`처럼 대화상자 없이 바로 저장하고 링크를 삽입하는 것입니다.
   - MM처럼 **미리보기가 있는 파일명 확인 프롬프트**는 설정으로 켜는 옵션으로 둡니다.
   - 포맷은 PNG를 기본으로 합니다(MM: 캡처 이미지는 PNG가 가장 작음).
4. **상태바 단어·문자 수 + 선택 영역 카운트 + 클릭 시 상세 팝업** (Typora·Obsidian·MarkText v0.20)
   - 팝업에는 줄 수 / 문자 수(공백 포함·제외) / 예상 읽기 시간을 보여 줍니다.
   - 한국어 사용자이므로 **CJK 단어 수 처리**(Obsidian)나 "문자 수 우선 표시" 토글(Zettlr의 Word Counter 설정)이 중요합니다.
5. **외부 변경 감지를 MM 규칙으로** (+ 선택적으로 Typora식 임시본 복구)
   - 미수정 문서는 디스크 내용으로 조용히 다시 읽고, 수정 중인 문서는 저장할 때 "내 것 유지 / 디스크 것 불러오기" 중에서 고르게 합니다.
   - Compare는 V1 범위 밖으로 둡니다.
   - Zettlr의 "항상 자동 반영" 토글을 하나 둡니다.
   - 인코딩은 ghostwriter 교훈대로 **BOM 없는 UTF-8을 기본 가정**하되, 원본에 BOM이 있었는지 여부는 저장할 때 보존합니다. MM #48 같은 무단 변환 불만을 피하기 위해서입니다.

**차순위 후보**: 미리보기 토글 `F12`와 분리 창 `Shift+F12`(MM), 포커스 모드(Typora `F8`, ghostwriter의 문장·문단 단위 선택), 아웃라인 사이드바(커서를 따라 하이라이트, MarkText v0.20). 모두 가치가 크지만 FlowDocument 스크롤 동기화 비용을 먼저 확인해야 합니다.

**참고 사항**
- MarkText는 이제 "방치"가 아니라 "2026년 부활, 0.20 rc 단계"로 분류하는 게 맞습니다.
- 아이디어 참고용 오픈소스는 MarkText(MIT)가 가장 자유롭습니다. Zettlr와 ghostwriter는 GPL-3.0입니다. MM은 소스가 공개돼 있지만 재배포 금지 상용 라이선스라서 동작만 참고해야 합니다.

result: Memojang 참고용으로 편집기 6종의 표·이미지·미리보기·저장·통계 UX를 출처와 함께 비교했습니다. 핵심은 세 가지입니다. MarkText는 4년 멈췄다가 2026년에 다시 개발이 시작됐습니다. Markdown Monster는 대화상자·그리드형 표 편집기를 쓰지만 재배포가 금지된 상용 소스입니다. Memojang에는 Tab 이동 시 자동 정렬되는 표 편집 등 5가지를 가볍게 가져올 만합니다.
