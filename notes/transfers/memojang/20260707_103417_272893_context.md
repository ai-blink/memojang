## Objective

`osk 6-7%`가 **CPU 사용률 6-7%** 말하는 거죠?

그럼 Memojang 문제가 아니라 Windows **화상 키보드(OSK, On-Screen Keyboard)** 프로세스가 계속 CPU를 쓰는 상태일 가능성이 큽니다. 앱 연결 창이나 텍스트 입력 UI가 떠 있을 때 OSK/터치 키보드 관련 프로세스가 붙어서 그럴 수 있어요.

빠르게 확인:

```powershell
Get-Process osk,TabTip -ErrorAction SilentlyContinue | Select-Object ProcessName,Id,CPU,MainWindowTitle
```

끄기:

```powershell
Stop-Process -Name osk -Force -ErrorAction SilentlyContinue
Stop-Process -Name TabTip -Force -ErrorAction SilentlyContinue
```

Memojang이 먹는지 확인하려면:

```powershell
Get-Process Memojang.App -ErrorAction SilentlyContinue | Select-Object ProcessName,Id,CPU,MainWindowTitle
```

`osk`만 6-7%고 `Memojang.App` CPU가 거의 0이면 Memojang 쪽 응답 없음 원인은 아닐 가능성이 높습니다.
