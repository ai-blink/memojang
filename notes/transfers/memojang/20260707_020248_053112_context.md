## Objective

맞아요. CommonMark 기준으로 `#` 단독 줄은 “빈 H1 제목”으로 볼 수 있습니다. 다만 연속으로 나오면 사용 의도가 제목이라기보다 구분/메모/주석 느낌일 가능성이 커서 예외 처리하는 게 좋아 보여요.

제가 추천하는 규칙은 이겁니다.

- `#` 한 줄만 있음: 빈 제목으로 인정하되, 미리보기에서는 큰 빈 H1 공간 대신 작은 흐린 `#` 표시
- `#\n#\n#`처럼 연속됨: 빈 제목 여러 개로 크게 벌리지 않고, 하나의 “구분 블록”처럼 압축 렌더링
- `# 제목`: 정상 H1 제목
- `## 제목`, `### 제목`: 정상 제목
- 코드블록 안의 `#`: 절대 제목 처리하지 않음

즉 “문법적으로는 제목이 맞다”를 유지하되, 연속 빈 제목은 UX 예외로 다루는 방식입니다. 미리보기에서 과한 공백 폭탄이 안 생기고, 사용자가 `# # #`를 구분선처럼 쓴 의도도 살릴 수 있습니다.

` ```내용``` ` 박스 처리랑 같이 구현하면 됩니다.
