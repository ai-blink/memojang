원인:
`MainWindow.xaml`에서 `Assets/Memojang.ico`를 창 아이콘으로 참조하는데, `.ico`가 WPF Resource로 포함되지 않아서 시작 시 예외가 났습니다.

로그에 찍힌 핵심:
```text

```

수정:
- [Memojang.App.csproj](C:/ai/projects/memojang/src/Memojang.App/Memojang.App.csproj)에 `Assets\Memojang.ico`를 WPF `Resource`로 포함
- 시작 로그 추가: `%LOCALAPPDATA%\Memojang\startup.log`
- 창 먼저 띄우고 `.txt` 파일은 idle 타이밍에 비동기 로드
- 시작 후 `Activate()` 호출

검증:
- `.txt` 파일을 Windows shell open 방식으로 실행 성공
- 로그에 파일 로드 성공 확인
- `dotnet build .\Memojang.sln` 성공
- `dotnet test ...icon-resource-startup...` 48개 통과

이제 다시 `.txt` 더블클릭하면 떠야 합니다. 혹시 계속 안 뜨면 `%LOCALAPPDATA%\Memojang\startup.log` 내용을 보면 바로 원인 확인 가능합니다.
