## Objective

맞아요. `.txt` 파일 아이콘 더블클릭으로 앱이 실행되는 케이스였고, 그 경로에서 문제가 될 만한 부분을 고쳤습니다.

원인:
`App.OnStartup`에서 창을 띄우기 전에 `OpenDocument(...)`로 파일을 먼저 읽고 있었습니다. `.txt` 연결 실행에서는 파일 읽기/초기화가 먼저 걸리면 창이 뜨기 전부터 “응답 없음”처럼 보일 수 있습니다.

수정:
- 창을 먼저 `Show()` 함
- 시작 파일 경로는 그 다음 `DispatcherPriority.ApplicationIdle`에서 로드
- 시작 파일 읽기는 `File.ReadAllTextAsync`로 비동기 처리

변경 파일:
- [App.xaml.cs](C:/ai/projects/memojang/src/Memojang.App/App.xaml.cs)
- [MainWindow.Files.cs](C:/ai/projects/memojang/src/Memojang.App/MainWindow.Files.cs)

검증:
- `dotnet test .\tests\Memojang.Tests\Memojang.Tests.csproj -p:OutDir=C:\ai\projects\memojang\artifacts\test-bin\startup-file-open\` 통과, 48개 테스트 통과
- `Memojang.App.exe "sample.txt"` 형태 실행 스모크 통과
- `dotnet build .\Memojang.sln` 성공, 경고 0 / 오류 0

중요: Windows 파일 연결이 예전 exe나 publish 폴더를 보고 있으면, 지금 빌드된 exe로 다시 연결해야 반영됩니다. 지금 갱신된 Debug exe는 `C:\ai\projects\memojang\src\Memojang.App\bin\Debug\net10.0-windows\Memojang.App.exe` 입니다.
