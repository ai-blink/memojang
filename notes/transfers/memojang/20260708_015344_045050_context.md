## Objective

맞아요, 지금은 좀 지저분합니다. 이유는 **서로 다른 역할 2개 + 루트 중복 1개**가 겹쳐서 그래요.

1. `research-router`
   - 리서치 **시작 전 단일 진입점**
   - “이 요청을 웹 검색으로 할지, 공식 문서로 볼지, Ollama 요약을 붙일지, 질문을 되물을지”를 고르는 라우터
   - 지금 사용자가 원한 “리서치 전용 1개”는 이쪽이 맞습니다.

2. `research-route`
   - 리서치 **완료 후 저장/분류 라우터**
   - 조사 결과를 전역 지식 / 프로젝트 notes로 나누고 `agent-brain`에 ingest하는 용도
   - 이름이 비슷하지만 “research를 수행”하는 게 아니라 “research 결과를 route/store”하는 스킬입니다.

3. `research-route`가 `.codex`와 `.agents`에 둘 다 있음
   - `C:/Users/user/.codex/skills/research-route/SKILL.md`
   - `C:/Users/user/.agents/skills/research-route/SKILL.md`
   - 이건 마이그레이션/호환 루트가 같이 노출돼서 생긴 **중복 이름 충돌**입니다.
   - Codex 세션이 `.codex/skills`와 `.agents/skills`를 둘 다 읽으니까 같은 이름이 두 번 뜹니다.

정리하면 현재 권장 canonical은 이렇게 두는 게 깔끔합니다.

- 리서치 시작: `research-router`
- 리서치 결과 저장: `.codex/skills/research-route`
- `.agents/skills/research-route`는 legacy/reference 취급하거나 이름을 바꿔 충돌 제거

즉 “많은 이유”는 설계상 필요한 건 `router`와 `route` 두 개뿐인데, `research-route`가 두 루트에 중복으로 남아 있어서 많아 보이는 겁니다.  
정리하려면 `.agents` 쪽을 deprecated 표시하거나 `research-route-legacy`로 바꾸는 게 제일 덜 위험합니다.
